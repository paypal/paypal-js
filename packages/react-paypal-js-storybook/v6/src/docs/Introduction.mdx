# PayPal v6 Web SDK — React Components

This Storybook is an interactive reference for [`@paypal/react-paypal-js`](https://www.npmjs.com/package/@paypal/react-paypal-js) (v6),
the React wrapper around PayPal's v6 Web SDK. Every button in the **Buttons**,
**Card Fields**, and **Braintree** sections is a live, editable example — change
the controls and watch the component re-render.

The **Documentation** pages collect the cross-cutting knowledge you
need _around_ the components: how to set up credentials, what your server has to
provide, and how payment-method eligibility works.

## How the pieces fit together

A checkout spans three tiers — the React app in the browser, **your** server, and
PayPal. The React components never touch your secret or the amount; those stay on
your server.

1. **Load** — [`PayPalProvider`](?path=/docs/v6-documentation-getting-started--docs)
   fetches a browser-safe `clientId` (or client token) from your server, then loads
   the SDK once and shares a single checkout-scoped instance.
2. **Eligibility** — `useEligibleMethods()` asks your server's
   `find-eligible-methods` endpoint which methods to render for this buyer, merchant,
   and amount. See [Eligibility and Hydration](?path=/docs/v6-documentation-eligibility-and-hydration--docs).
3. **Create order** — when the buyer clicks a button, its `createOrder` calls your
   server, which calls PayPal's Orders API and returns an `orderId`.
4. **Capture** — after the buyer approves, `onApprove` calls your server again to
   capture the order through the Orders API.

Steps 3 and 4 are server-side on purpose — see
[Server-Side Integration](?path=/docs/v6-documentation-server-side-integration--docs).
